# Zomato Power BI Dashboard

An interactive Power BI dashboard created to analyze Zomato restaurant and food data.

## Project Overview

This project uses Power BI to explore restaurant performance, ratings, prices, customer votes, cuisines, cities, and bestseller information.

The dashboard allows users to interact with the data using filters and different visualizations.

## Dashboard Features

- Total restaurants and food items
- Average dining and delivery ratings
- Restaurant performance analysis
- City-wise restaurant analysis
- Cuisine analysis
- Food price analysis
- Customer votes and popularity
- Bestseller analysis
- Interactive slicers
- Restaurant performance matrix
- Rating gauge
- Price vs. popularity analysis

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Visualizations

The report includes:

- KPI Cards
- Bar Charts
- Column Charts
- Pie/Donut Chart
- Gauge
- Matrix
- Scatter Chart
- Slicers

## File

`Zomato_Sales_Report.pbix` — Power BI report containing the complete dashboard.

## Purpose

The purpose of this project is to practice data cleaning, data analysis, DAX, and interactive dashboard development using Power BI.
